# 接口文档索引

小程序客户端与后台管理接口已拆分维护，避免将匿名公开接口和后台 Token 接口混用。

| 文档 | 面向对象 | 地址/路径 |
| --- | --- | --- |
| [小程序接口](./小程序接口/README.md) | 小程序客户端 | `https://73ham.top/api/...` |
| [后台小程序管理接口](./后台接口/小程序管理.md) | 后台 Vue 管理页 | `/prod-api/system/miniapp/...` |

服务端统一为两个类：`MiniappApiController` 承载 `/api/...` 下的所有小程序接口；`MiniappManageController` 承载 `/system/miniapp/...` 下的用户、会员、日志和中继台管理接口。其他系统 Controller 保持原有结构。
