## 1. 小程序用户验证接口

### POST `/miniapp/login/verify`

**认证方式：** 匿名访问（@Anonymous），无需登录 token

**业务逻辑：**
1. 读取 `sys_config` 表中 `miniapp.valid.ids` 配置，验证 `miniappId` 是否在白名单
2. 不在白名单 → 返回拒绝
3. 在白名单 → 查询 `miniapp_user` 表（按 `miniapp_id` + `openid`）
4. 不存在 → 自动新增用户（`is_member=0`, `status=0`）
5. 存在 → 检查 `status`，停用则拒绝
6. 返回用户信息（是否会员、会员到期时间）
7. 全程自动记录接口日志到 `miniapp_api_log` 表

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| miniappId | string | 是 | 小程序标识（如 `wx_hnml`） |
| openid | string | 是 | 用户在该小程序下的 openid |
| wxId | string | 是 | 用户微信id（union_id，方便后台管理） |
| nickname | string | 否 | 用户昵称（首次验证时带入） |
| ip | string | 否 | 请求IP（用于日志记录） |

**请求示例：**

```json
POST /miniapp/login/verify
Content-Type: application/json

{
  "miniappId": "wx_hnml",
  "openid": "oABC123456789",
  "wxId": "union_id_xxx",
  "nickname": "张三",
  "ip": "192.168.1.100"
}
```

**响应示例（成功 - 新增用户）：**

```json
{
  "msg": "用户验证成功(新增)",
  "code": 200,
  "userId": 1,
  "isMember": 0,
  "memberExpire": null
}
```

**响应示例（成功 - 已有用户）：**

```json
{
  "msg": "用户验证成功",
  "code": 200,
  "userId": 1,
  "isMember": 1,
  "memberExpire": "2026-12-31 23:59:59"
}
```

**响应示例（拒绝 - 小程序标识不在白名单）：**

```json
{
  "msg": "小程序标识不在白名单中,拒绝访问",
  "code": 500
}
```

**响应示例（拒绝 - 用户已停用）：**

```json
{
  "msg": "用户已停用,拒绝访问",
  "code": 500
}
```

## 2. 用户管理接口（后台）

> 以下接口需要后台登录，请求头携带 `Authorization: Bearer <token>`

### GET `/miniapp/user/list`

**功能：** 查询小程序用户列表（分页）

**请求参数（Query）：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| miniappId | string | 否 | 小程序标识（精确匹配） |
| openid | string | 否 | openid（模糊查询） |
| wxId | string | 否 | 微信id（模糊查询） |
| nickname | string | 否 | 昵称（模糊查询） |
| isMember | int | 否 | 是否会员：0否 1是 |
| status | string | 否 | 状态：0正常 1停用 |

**响应示例：**

```json
{
  "code": 200,
  "rows": [
    {
      "userId": 1,
      "miniappId": "wx_hnml",
      "openid": "oABC123456789",
      "wxId": "union_id_xxx",
      "nickname": "张三",
      "isMember": 1,
      "memberExpire": "2026-12-31 23:59:59",
      "status": "0",
      "createTime": "2026-09-08 16:30:00",
      "updateTime": "2026-09-08 17:00:00",
      "remark": null
    }
  ],
  "total": 1
}
```

### GET `/miniapp/user/{userId}`

**功能：** 获取用户详情

**响应示例：**

```json
{
  "code": 200,
  "data": {
    "userId": 1,
    "miniappId": "wx_hnml",
    "openid": "oABC123456789",
    "wxId": "union_id_xxx",
    "nickname": "张三",
    "isMember": 1,
    "memberExpire": "2026-12-31 23:59:59",
    "status": "0"
  }
}
```

### PUT `/miniapp/user`

**功能：** 修改用户信息（昵称、会员状态、会员到期时间、状态、备注）

**权限标识：** `miniapp:user:edit`

**请求体：**

```json
PUT /miniapp/user
Content-Type: application/json

{
  "userId": 1,
  "nickname": "张三丰",
  "isMember": 1,
  "memberExpire": "2027-06-30 23:59:59",
  "status": "0",
  "remark": "VIP会员"
}
```

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

### PUT `/miniapp/user/member`

**功能：** 快捷修改会员状态（是否会员 + 到期时间）

**权限标识：** `miniapp:user:edit`

**请求体：**

```json
PUT /miniapp/user/member
Content-Type: application/json

{
  "userId": 1,
  "isMember": 1,
  "memberExpire": "2027-12-31 23:59:59"
}
```

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

## 3. 接口日志接口（后台）

> 以下接口需要后台登录，请求头携带 `Authorization: Bearer <token>`

### GET `/miniapp/log/list`

**功能：** 查询接口日志列表（分页）

**请求参数（Query）：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| type | string | 否 | 日志类型（如"接口日志"） |
| des | string | 否 | 接口名称（模糊查询） |
| result | string | 否 | 请求结果：成功/失败/拒绝 |
| miniappId | string | 否 | 小程序标识 |
| openid | string | 否 | 用户openid |
| ip | string | 否 | 请求IP |
| params[beginTime] | string | 否 | 开始日期（YYYY-MM-DD） |
| params[endTime] | string | 否 | 结束日期（YYYY-MM-DD） |

**响应示例：**

```json
{
  "code": 200,
  "rows": [
    {
      "logId": 1,
      "type": "接口日志",
      "des": "小程序用户验证",
      "result": "成功",
      "details": "{\"miniappId\":\"wx_hnml\",\"openid\":\"oABC123456789\",\"wxId\":\"union_id_xxx\"}",
      "miniappId": "wx_hnml",
      "openid": "oABC123456789",
      "reqUrl": "/miniapp/login/verify",
      "respTime": 45,
      "ip": "192.168.1.100",
      "createTime": "2026-09-08 16:35:00"
    }
  ],
  "total": 1
}
```

### DELETE `/miniapp/log/{logIds}`

**功能：** 删除指定日志

**权限标识：** `miniapp:log:remove`

**路径参数：** `logIds` — 日志ID，多个用逗号分隔（如 `1,2,3`）

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

### DELETE `/miniapp/log/clean`

**功能：** 清空所有接口日志

**权限标识：** `miniapp:log:remove`

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

## 4. 数据库表结构

### miniapp_user（小程序用户表）

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | bigint | 主键，自增 |
| miniapp_id | varchar(64) | 小程序标识 |
| openid | varchar(64) | 用户openid |
| wx_id | varchar(64) | 微信id（union_id） |
| nickname | varchar(64) | 昵称（可选） |
| is_member | tinyint | 是否会员：0否 1是 |
| member_expire | datetime | 会员到期时间 |
| status | char(1) | 状态：0正常 1停用 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |
| remark | varchar(500) | 备注 |

**索引：**
- `uk_miniapp_openid` (miniapp_id, openid) — 唯一索引
- `idx_wx_id` (wx_id) — 普通索引

### miniapp_api_log（接口日志表）

| 字段 | 类型 | 说明 |
|---|---|---|
| log_id | bigint | 主键，自增 |
| type | varchar(50) | 日志类型（接口日志） |
| des | varchar(200) | 接口名称 |
| result | varchar(50) | 请求结果 |
| details | text | 入参记录（JSON） |
| miniapp_id | varchar(64) | 小程序标识 |
| openid | varchar(64) | 用户openid |
| req_url | varchar(500) | 请求URL |
| resp_time | int | 响应耗时（ms） |
| ip | varchar(50) | 请求IP |
| create_time | datetime | 创建时间 |

**索引：**
- `idx_miniapp_openid` (miniapp_id, openid) — 普通索引
- `idx_type` (type) — 普通索引
- `idx_create_time` (create_time) — 普通索引

## 5. 配置说明

### 小程序白名单配置

在若依后台「参数管理」页面配置，或直接操作 `sys_config` 表：

| 配置键 | 配置值 | 说明 |
|---|---|---|
| `miniapp.valid.ids` | `wx_hnml,wx_ham` | 逗号分隔的小程序标识列表 |

- 配置存在才执行业务逻辑
- 配置值为空或配置不存在 → 所有小程序请求被拒绝
- 在后台「参数管理」可直接增删标识，无需改代码

### 前端菜单

| 菜单ID | 菜单名称 | 类型 | 路径 | 组件 | 权限标识 |
|---|---|---|---|---|---|
| 2000 | 小程序管理 | 目录(M) | miniapp | — | — |
| 2001 | 用户管理 | 菜单(C) | user | miniapp/user/index | miniapp:user:list |
| 2002 | 用户编辑 | 按钮(F) | — | — | miniapp:user:edit |
| 2003 | 用户导出 | 按钮(F) | — | — | miniapp:user:export |
| 2004 | 接口日志 | 菜单(C) | log | miniapp/log/index | miniapp:log:list |
| 2005 | 日志删除 | 按钮(F) | — | — | miniapp:log:remove |

### 日志工具类使用

在任意 Java 代码中调用 `MiniappLogUtil.log()` 记录接口日志：

```java
import com.ruoyi.system.utils.MiniappLogUtil;

MiniappLogUtil.log(
    "接口日志",           // type: 日志类型
    "小程序用户验证",       // des: 接口名称
    "成功",               // result: 请求结果
    "{\"openid\":\"xxx\"}", // details: 入参JSON
    "wx_hnml",            // miniappId: 小程序标识
    "oABC123",            // openid: 用户openid
    "/miniapp/login/verify", // reqUrl: 请求URL
    45L,                  // respTime: 响应耗时(ms)
    "192.168.1.100"       // ip: 请求IP
);
```

## SQL 文件说明

SQL 文件位于 `docs/sql/` 目录下，按数字顺序执行：

| 顺序 | 文件名 | 说明 |
|---|---|---|
| 1 | `1-若依基础数据.sql` | 若依基础表结构和初始数据 |
| 2 | `2-菜单初始化SQL.sql` | 小程序管理菜单（ID 2000-2005） |
| 3 | `3-定时任务表.sql` | Quartz 定时任务框架表 |
| 4 | `4-小程序建表脚本.sql` | 小程序用户表 + 接口日志表 |

执行方式：
```bash
mysql -uroot -p --default-character-set=utf8mb4 ry-vue < "1-若依基础数据.sql"
mysql -uroot -p --default-character-set=utf8mb4 ry-vue < "2-菜单初始化SQL.sql"
mysql -uroot -p --default-character-set=utf8mb4 ry-vue < "3-定时任务表.sql"
mysql -uroot -p --default-character-set=utf8mb4 ry-vue < "4-小程序建表脚本.sql"
```
