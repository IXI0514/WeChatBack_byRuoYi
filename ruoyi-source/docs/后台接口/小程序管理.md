# 后台小程序管理接口

统一实现类：`MiniappManageController`，路径前缀 `/system/miniapp`。用户、会员、日志和中继台管理方法集中维护；Service、Mapper 按业务分别复用。

用户查询/详情要求 `miniapp:user:list`，修改/会员设置要求 `miniapp:user:edit`；日志查询要求 `miniapp:log:list`，删除/清空要求 `miniapp:log:remove`。这些权限沿用现有菜单，无需新增 SQL。

本文件仅面向已登录的若依后台管理页。请求由 Vue 前端经 `/prod-api/` 代理，实际外部地址为：

```text
https://73ham.top/prod-api/system/miniapp/...
```

小程序客户端不得调用本文件中的接口；客户端接口见[小程序接口](../小程序接口/README.md)。

## 认证

请求需携带后台登录后获得的 Token：

```text
Authorization: Bearer <token>
```

## 小程序用户管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/system/miniapp/user/list` | 分页查询用户 |
| GET | `/system/miniapp/user/{userId}` | 查询用户详情 |
| PUT | `/system/miniapp/user` | 修改用户资料、状态或会员信息 |
| PUT | `/system/miniapp/user/member` | 快捷修改会员状态与到期时间 |

## 小程序接口日志

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/system/miniapp/log/list` | 分页查询接口日志 |
| DELETE | `/system/miniapp/log/{logIds}` | 删除指定日志 |
| DELETE | `/system/miniapp/log/clean` | 清空接口日志 |

## 中继台管理

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/system/miniapp/repeater/list` | `miniapp:repeater:list` | 分页列表与筛选 |
| GET | `/system/miniapp/repeater/{repeaterId}` | `miniapp:repeater:list` | 查询详情 |
| POST | `/system/miniapp/repeater` | `miniapp:repeater:add` | 新增 |
| PUT | `/system/miniapp/repeater` | `miniapp:repeater:edit` | 编辑、维护或停用 |
| DELETE | `/system/miniapp/repeater/{repeaterIds}` | `miniapp:repeater:remove` | 删除 |

中继台详细配置由后台页面以单字段编辑，提交时自动组装为 `radioConfig` JSON。该字段不得保存控制口令、DTMF 控制码、加密密钥或设备管理地址。
