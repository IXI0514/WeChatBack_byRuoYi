# 小程序 API 接口说明

统一实现类：`MiniappApiController`，路径前缀 `/api`。当前两个接口在方法上标注 `@Anonymous`。

正式地址为 `https://73ham.top/api`；后台管理接口另见 [小程序管理](../后台接口/小程序管理.md)。

## 中继台公开查询

### 请求

```text
GET https://73ham.top/api/repeater/public/list
```

无需登录，只返回状态正常且设置为公开的中继台。

| 查询参数 | 必填 | 说明 |
| --- | --- | --- |
| province | 否 | 省份精确过滤 |
| city | 否 | 城市精确过滤 |
| repeaterName | 否 | 中继台名称模糊过滤 |
| callSign | 否 | 呼号模糊过滤 |
| operationMode | 否 | `ANALOG`、`DIGITAL` 或 `MIXED` |

示例：

```text
https://73ham.top/api/repeater/public/list?province=湖南省&city=长沙市&operationMode=ANALOG
```

### 响应

`data` 为中继台数组，包含名称、呼号、省市、类型、上下行频率、最后核验时间、`radioConfig` 和备注。

`radioConfig` 为 JSON 字符串，客户端可用 `JSON.parse` 解析。管理员不得在其中录入控制口令、DTMF 控制码、密钥或设备管理地址；当前接口没有额外的敏感字段过滤。

## 登录验证

### 请求

```text
POST https://73ham.top/api/login/verify
Content-Type: application/json
```

```json
{
  "miniappId": "wx_hnml",
  "openid": "微信用户 openid",
  "wxId": "微信用户 unionid 或业务侧标识",
  "nickname": "昵称"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| miniappId | 是 | 小程序标识，必须存在于后台白名单配置 |
| openid | 是 | 微信用户 OpenID |
| wxId | 是 | UnionID 或当前业务使用的用户标识 |
| nickname | 否 | 用户昵称 |

服务端按 `miniappId + openid` 查询用户；用户不存在时自动创建普通用户，已停用用户会被拒绝。

### 响应示例

```json
{
  "code": 200,
  "msg": "用户验证成功(新增)",
  "userId": 1,
  "isMember": 0,
  "memberExpire": null
}
```

### 小程序调用示例

```js
wx.request({
  url: 'https://73ham.top/api/login/verify',
  method: 'POST',
  header: { 'content-type': 'application/json' },
  data: {
    miniappId: 'wx_hnml',
    openid,
    wxId,
    nickname
  }
})
```

不要由小程序客户端伪造服务器 IP；服务端应从网关转发头或请求连接中获取真实来源 IP。


## 身份验证说明

当前登录验证接口接收调用方传入的 openid / wxId，用于查询或登记用户，不执行微信 code 换取 OpenID，也不签发登录 Token；不能将其返回结果作为可信身份认证凭证。
