# 22 · 小程序 API 接口说明

统一实现类：`MiniappApiController`，路径前缀 `/api`。`@Anonymous` 仅跳过后台 JWT；中继台查询必须通过独立 AES-GCM 凭证校验。

正式地址为 `https://73ham.top/api`；后台管理接口另见 [小程序管理](../后台接口/小程序管理.md)。

## 全部小程序业务接口的 Token 规则

后台「系统管理 → 参数设置」配置 `miniapp.token.expire.minutes`，单位为分钟。正整数（最多 9 位），例如 `30` 表示 30 分钟；参数不存在或留空表示不过期，0、负数、小数及非数字返回 503 配置错误。

所有小程序业务接口使用同一规则：GET `/api/repeater/list` 在查询参数传 token；POST `/api/login/verify` 在 JSON 中传 token，且凭证中的 ID 必须与 miniappId 相同。POST `/api/token` 是领取入口，不需要已有 token。后台管理 JWT 不受影响。

有效期按签发时间计算；修改参数后，已有 token 也按新规则校验（缩短可能立即过期，清空后原来过期的 token 可能重新可用）。在后台参数页面修改会更新缓存；直接执行 SQL 后需刷新参数缓存。新环境初始化已包含参数，已有环境可执行 `docs/sql/7-小程序Token有效期参数.sql`，默认空值，不覆盖已有值。

不过期仍校验格式、AES 完整性和白名单，且不允许签发时间超过服务器未来 120 秒。原有 AES 算法、明文和 AAD 字符串 `GET /api/repeater/list` 保持兼容；该 AAD 在当前版本是固定协议字符串，不限制 token 只能用于 list。接口获取或本地生成的 token 都可用于上述业务接口。

## 获取 Token

`POST https://73ham.top/api/token`，`Content-Type: application/json`，仅传小程序标识。

```json
{
  "miniappId": "wx_ham"
}
```

miniappId 必填且只接受字符串，为 1～64 位字母、数字、下划线或连字符，须在 `miniapp.valid.ids` 白名单内。不再接收 clientSecret，传入其他字段返回 400。

服务端使用 `.env` 已有的 `MINIAPP_API_AES_KEY` 加密签发 token，解码后须为 32 字节；接口调用方无需传入或持有密钥。重新构建并创建后端容器后生效，无需修改 SQL 或增加 env 配置。

```json
{
  "code": 200,
  "msg": "操作成功",
  "token": "v1.随机IV.密文与认证标签",
  "expiresIn": -1,
  "expiresAt": null
}
```

上例为未配置有效期。expiresIn 为有效秒数（系统参数分钟 × 60），-1 表示不过期；expiresAt 为 Unix 秒级过期时间，不过期时为 null。返回值反映签发当时的设置，实际校验以当前参数为准。成功响应禁止缓存。Token 不能作为后台 JWT。HTTP/JSON code：400 入参错误，403 标识不在白名单，503 服务端 AES 密钥或有效期参数异常。业务接口对缺失、无效、过期 token 返回 401。

```js
wx.request({
  url: 'https://73ham.top/api/token',
  method: 'POST',
  header: { 'content-type': 'application/json' },
  data: { miniappId: 'wx_ham' },
  success({ statusCode, data }) {
    if (statusCode !== 200 || data.code !== 200) return
    wx.request({
      url: 'https://73ham.top/api/repeater/list',
      method: 'GET',
      data: { token: data.token, province: '湖南省' }
    })
  }
})
```

任何知道白名单 miniappId 的人都可以领取 token，此流程不验证调用方或用户身份，不能保护私密数据。也可继续持有 AES 密钥在小程序本地生成，格式不变，有效期统一由系统参数决定。必须使用 HTTPS，不要记录完整 token；当前未实现发放频率限制，公网部署建议在网关限流。

## 提交中继台审核

\`POST https://73ham.top/api/repeater/submit\`，\`Content-Type: application/json\`。需携带与 miniappId 匹配的 token；有效期遵从统一参数规则。

\`\`\`json
{
  "miniappId": "wx_ham",
  "token": "POST /api/token 获取的凭证",
  "repeaterName": "长沙示例中继台",
  "callSign": "BG7XXX",
  "province": "湖南省",
  "city": "长沙市",
  "operationMode": "DIGITAL",
  "uplinkFrequencyMhz": 430.125,
  "downlinkFrequencyMhz": 438.125,
  "radioConfig": {
    "digital": {
      "protocol": "DMR",
      "color_code": 1,
      "slots": [{ "slot": 1 }]
    }
  },
  "remark": "资料来源及说明"
}
\`\`\`

必填：miniappId、token、名称、省、市、类型、上行/下行频率。radioConfig 和备注可选；radioConfig 必须为 JSON 对象，不可提交状态、公开标识、审核人等后台字段。

名称去重规则为：去掉首尾和内部空白、英文转小写后比较。已存在正式中继台或曾提交审核的同名资料不可再次提交；数据库唯一索引同时防止并发重复。成功返回 HTTP 200、submissionId 和 reviewStatus=\`0\`；重复提交返回 409；审核由后台完成，只有审核通过才进入中继台公开列表。

后台审核接口：\`GET /system/miniapp/repeater/submission/list\`、\`PUT /system/miniapp/repeater/submission/review\`，需要权限 \`miniapp:repeater:review\`。review 请求只传 submissionId、reviewStatus（\`1\` 通过 / \`2\` 驳回）、reviewRemark；通过时自动创建状态正常、公开的中继台。部署已有环境需执行 [8-中继台审核提交增量.sql](../sql/8-中继台审核提交增量.sql)。

## 中继台公开查询

### 请求

```text
GET https://73ham.top/api/repeater/list?token=<客户端生成的加密凭证>
```

只返回正常、公开的中继台。可调用上述接口获取 Token，也可继续使用下方本地生成方式；有效期由 `miniapp.token.expire.minutes` 决定，未配置或留空不过期。

### 配置

用 `openssl rand -base64 32` 生成密钥，服务器 `.env` 配置 `MINIAPP_API_AES_KEY`，调用方使用相同值。后台参数 `miniapp.valid.ids` 加入 `wx_ham`。配置后重新创建后端容器。

### Token 生成逻辑（Node.js，可直接运行）

```js
const crypto = require('crypto')

function createMiniappToken(miniappId, keyBase64) {
  if (!/^[A-Za-z0-9_-]{1,64}$/.test(miniappId)) {
    throw new Error('小程序标识格式错误')
  }
  const key = Buffer.from(keyBase64, 'base64')
  if (key.length !== 32) throw new Error('密钥必须为 32 字节')

  const timestamp = Math.floor(Date.now() / 1000)
  const plaintext = `${miniappId}\n${timestamp}`
  const iv = crypto.randomBytes(12)
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv, {
    authTagLength: 16
  })
  cipher.setAAD(Buffer.from('GET /api/repeater/list', 'utf8'))
  const encrypted = Buffer.concat([
    cipher.update(plaintext, 'utf8'),
    cipher.final(),
    cipher.getAuthTag()
  ])
  return `v1.${iv.toString('base64url')}.${encrypted.toString('base64url')}`
}

const token = createMiniappToken('wx_ham', process.env.MINIAPP_API_AES_KEY)
// 将 token 放入查询参数 data.token，不再通过请求头传递
```

微信小程序不能直接使用 Node 的 `crypto` / `Buffer`；移植时使用支持 AES-GCM 的库，严格保持上述明文、AAD、12 字节随机 IV、16 字节标签和 Base64URL 格式。

### 小程序请求示例

```js
// token 为 /api/token 返回的凭证，也兼容本地生成的凭证
wx.request({
  url: 'https://73ham.top/api/repeater/list',
  method: 'GET',
  data: { token, province: '湖南省', city: '长沙市' },
  success({ statusCode, data }) {
    if (statusCode === 200 && data.code === 200) {
      const repeaters = data.data
      // 使用中继台列表
    }
  }
})
```

### 查询参数

| 查询参数 | 必填 | 说明 |
| --- | --- | --- |
| token | 是 | 获取接口返回或本地生成的 AES-GCM 凭证，最多 1024 字符；缺失、空值、无效或过期返回 401，重复传入返回 400 |
| province | 否 | 省份精确过滤，最多 30 字符 |
| city | 否 | 城市精确过滤，最多 30 字符；必须同时提供省份 |
| repeaterName | 否 | 名称或呼号模糊过滤，最多 100 字符 |
| callSign | 否 | 呼号模糊过滤，最多 50 字符 |
| operationMode | 否 | `ANALOG`、`DIGITAL` 或 `MIXED` |

示例：

```text
https://73ham.top/api/repeater/list?token=<生成的凭证>&province=湖南省&city=长沙市&operationMode=ANALOG
```

### 响应

筛选参数去除首尾空格，空字符串视为未提供；token 按原值校验，不进行去空格处理。拒绝控制字符、未知参数和重复参数。不接收 userId、status、isPublic 或实体的其他字段。省市按名称组合查询，不使用封闭行政区划白名单（后台支持自定义地区），组合无数据时返回空数组。

GET 的 data 会拼接到 URL，不是 JSON 请求体；不再读取 X-Miniapp-Token 请求头。请使用 HTTPS，避免在访问日志中记录完整查询字符串，以免泄露 token。

HTTP 状态与 JSON code 对应：200 成功，400 参数错误，401 凭证无效/过期，403 小程序未授权，503 服务端密钥未正确配置。

`data` 为中继台数组，包含名称、呼号、省市、类型、上下行频率、最后核验时间、`radioConfig` 和备注。

`radioConfig` 为 JSON 字符串，客户端可用 `JSON.parse` 解析。管理员不得在其中录入控制口令、DTMF 控制码、密钥或设备管理地址；当前接口没有额外的敏感字段过滤。

## 登录验证

### 请求

```text
POST https://73ham.top/api/login/verify
Content-Type: application/json
```

```json
{
  "miniappId": "wx_hnml",
  "token": "与该 miniappId 对应的凭证",
  "openid": "微信用户 openid",
  "wxId": "微信用户 unionid 或业务侧标识",
  "nickname": "昵称"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| miniappId | 是 | 小程序标识，必须存在于后台白名单配置 |
| token | 是 | 同一 miniappId 的凭证；缺失/无效/过期返回 HTTP 401，ID 不匹配返回 403，配置错误返回 503 |
| openid | 是 | 微信用户 OpenID |
| wxId | 是 | UnionID 或当前业务使用的用户标识 |
| nickname | 否 | 用户昵称 |

服务端按 `miniappId + openid` 查询用户；用户不存在时自动创建普通用户，已停用用户会被拒绝。

### 响应示例

```json
{
  "code": 200,
  "msg": "用户验证成功(新增)",
  "userId": 1,
  "isMember": 0,
  "memberExpire": null
}
```

### 小程序调用示例

```js
wx.request({
  url: 'https://73ham.top/api/login/verify',
  method: 'POST',
  header: { 'content-type': 'application/json' },
  data: {
    miniappId: 'wx_hnml',
    token,
    openid,
    wxId,
    nickname
  }
})
```

不要由小程序客户端伪造服务器 IP；服务端应从网关转发头或请求连接中获取真实来源 IP。


## 身份验证说明

当前登录验证接口接收调用方传入的 openid / wxId，用于查询或登记用户，不执行微信 code 换取 OpenID，也不签发登录 Token；不能将其返回结果作为可信身份认证凭证。
