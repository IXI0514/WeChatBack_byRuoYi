# 中继台接口说明

## 小程序公开列表

GET /miniapp/repeater/public/list

无需登录。只返回 status 为 0 且 isPublic 为 0 的中继台。

可选筛选参数：

| 参数 | 说明 |
|---|---|
| province | 省份精确过滤 |
| city | 城市精确过滤 |
| repeaterName | 中继台名称模糊过滤 |
| callSign | 呼号模糊过滤 |
| operationMode | ANALOG、DIGITAL、MIXED |

响应 data 是中继台数组，包含名称、呼号、省市、类型、上下行频率、最后核验时间、radioConfig 和备注。

## 后台管理

所有后台接口均需要登录。

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /miniapp/repeater/list | miniapp:repeater:list | 分页列表与筛选 |
| GET | /miniapp/repeater/{repeaterId} | miniapp:repeater:list | 详情 |
| POST | /miniapp/repeater | miniapp:repeater:add | 新增 |
| PUT | /miniapp/repeater | miniapp:repeater:edit | 编辑、维护或停用 |
| DELETE | /miniapp/repeater/{repeaterIds} | miniapp:repeater:remove | 删除 |

radioConfig 是 JSON 字符串。服务端保存前由后台页面校验 JSON 格式；其中不得保存口令、DTMF 控制码、加密密钥或设备管理地址。
