## 搭建纯静态个人博客（零依赖方案）
用户需求：个人博客站，纯静态、无环境依赖（放弃 Hugo 方案）。
技术选型：纯 HTML + CSS + JavaScript，无框架、无构建、无运行时依赖。

### 产出文件
- `index.html` — 首页（Hero 区 + 文章卡片列表）
- `about.html` — 关于页
- `posts/` — 4 篇示例文章（hello-world、build-static-blog、reading-list-2026、markdown-guide）
- `assets/css/style.css` — 全部样式：CSS 变量双主题（亮/暗）、响应式、代码块、表格、引用等排版
- `assets/js/main.js` — 主题切换（localStorage 记忆）、移动端菜单、阅读进度条、代码复制按钮、页脚年份

### 关键设计决策
- 主题切换用 `data-theme` 属性 + CSS 变量，无需 JS 换肤
- 零外部资源（无 CDN 字体/图标），双击 index.html 即可离线打开
- 新增文章流程：复制 posts/ 模板 → 改内容 → 首页加卡片链接

### 预览
本地服务器: `python -m http.server 8080`（task iYKrfZ）
